## 📅 2026-09-10 ~ 2026-09-11（M4里程碑：FastAPI 后端搭建）
**状态**：✅ 通关（云端/本地双模型切换均测试成功）

### 🎯 目标
将散落的终端脚本重构为工程化代码（`main.py` + `models.py`），搭建 FastAPI 服务，实现云端与本地模型的一键切换。

### 🚧 踩坑记录与解决思路
*   **模块导入失败**：粘贴新代码后忘记保存导致 `ImportError`。解决：强制养成 `Ctrl+S` 习惯。
*   **云端 API 404**：`.env` 中 `BASE_URL` 多写了 `/chat/completions` 导致路径重复，去除多余后缀后解决。
*   **本地大模型 400**：LM Studio 未加载模型或模型标识符错误，正确加载并复制 Model Identifier 后解决。
*   **热重载陷阱**：`uvicorn --reload` 不重新读取 `.env` 文件，必须手动重启服务进程。

### 💡 核心心法
1. **分层排查**：FastAPI 返回 200 代表网络通，内部 JSON 的 404/400 才是业务错。
2. **脚本 vs 服务**：终端脚本的 `while True` 绝不能带入 FastAPI，否则会阻塞服务器。

## 📅 2026-09-11 ~ 2026-09-12（M5阶段：RAG 知识库建库）
**状态**：✅ 通关（成功切分文档，向量化存入 ChromaDB，向量库落盘 D 盘）

### 🎯 目标
完成多格式文档加载、切分、向量化，并在非系统盘建立本地 ChromaDB 向量库。

### 🚧 踩坑记录与解决思路
*   **Windows 路径转义**：单反斜杠 `\` 被 Python 识别为转义字符（如 `\x07`），导致文件读取失败。解决：路径前加 `r` 或使用正斜杠 `/`。
*   **HuggingFace 下载超时**：连接外网超时。解决：安装独立包，配置国内镜像端点，设置 `HF_HUB_DISABLE_SYMLINKS=1` 强制复制文件，并将模型手动下载至本地绝对路径彻底摆脱网络依赖。
*   **切分出 0 个小块**：测试文档内容太少，未达到设定的 `chunk_size` 阈值。解决：充实测试文档内容。

### 💡 核心心法
1. **路径安全**：Windows 路径一律加 `r` 或使用 `/`，能规避大部分读取错误。
2. **离线优先**：对于基础模型文件，提前本地下载，消除网络波动对开发的影响。
3. **分层排错**：建库失败先看切分块数（0 个说明内容少），再看向量生成（空列表说明软链接问题），最后看数据库写入。

## 📅 2026-09-12（M5 核心闭环：检索、API 集成与前端联调）
**状态**：✅ 通关（实现云端/本地/RAG 三模式切换，前端网页演示成功）

### 🎯 目标
编写 `query_kb.py` 实现检索与大模型问答，集成至 FastAPI 接口，开发 HTML 前端页面。

### 🚧 踩坑记录与解决思路
*   **路由优先级冲突**：`@app.get("/")` 拦截了前端页面请求。解决：将 API 路由改名，确保 `app.mount` 挂载代码位于所有路由定义的最后。
*   **前端元素重复**：整段 HTML 代码被重复粘贴两次，相同 `id` 导致 JS 只绑定第一个元素，出现两个输入框。解决：清空文件重新粘贴一份完整的 HTML。
*   **FastAPI 匹配顺序**：`app.mount` 必须放在所有的 `@app.get` / `@app.post` 下面。

### 💡 核心心法
1. **RAG 分层排错**：先测检索结果，再测 Prompt 拼接，最后测模型 API 调用。
2. **Prompt 是护栏**：在提示词里严厉声明“若资料中没有答案，请直接回答无法回答”，大模型才会乖乖听话。

## 📅 2026-09-13（M5 完美通关：多格式支持与离线模型加载）
**状态**：✅ 通关（支持 txt/md/pdf/docx 四种格式，解决网络超时与蓝屏崩溃，离线模型建库成功）

### 🎯 目标
扩展多格式文档加载，解决 HuggingFace 模型下载超时，实现本地离线加载。

### 🚧 踩坑记录与解决思路
*   **多线程导致系统蓝屏重启（核心大坑）**：`DirectoryLoader` 开启多线程导致 CPU/内存瞬间飙升，触发 Windows 硬件过热保护蓝屏重启。解决：彻底弃用高级封装，改用原生 Python 单线程循环配合 `try...except` 逐个加载，保证单文件解析失败不会影响全局。
*   **glob 通配符报错**：花括号写法不被底层库支持，导致读取 0 份文档。解决：放弃 glob 过滤，直接在循环中判断文件后缀进行动态路由。

### 💡 核心心法
1. **底层控制胜过黑盒封装**：高级封装（如 `DirectoryLoader`）容错性差，原生循环容错性极强、错误定位精准。
2. **硬件负载保护**：本地运行涉及大量计算（如嵌入模型推理）时，务必禁用多线程，避免触发系统保护重启。

## 📅 2026-09-14（前端体验优化与检索策略升级）
**状态**：✅ 通关（前端交互优化完成，RAG 模糊日期检索优化完成）

### 🎯 目标
优化前端交互体验，解决“精确日期”检索失效导致大模型拒绝回答的问题。

### 🚧 踩坑记录与解决思路
*   **精确日期检索失效**：用户问“9月13日”，知识库只有“9月11日~12日”内容，大模型因未找到确切日期而拒绝回答。解决：修改 Prompt 增加兜底策略：“若用户问了具体日期但资料中只有相近日期，请总结相近日期的内容并说明未找到精确日期”。

### 💡 核心心法
1. **Prompt 的权衡艺术**：优秀的 Prompt 不仅需要防幻觉，还需要具备“类比归纳”的兜底能力，避免“见死不救”。
2. **用户体验是生命线**：前端加入“思考中...”状态、回车发送、清空按钮，能大幅提升演示流畅度，避免用户狂点导致重复请求。
